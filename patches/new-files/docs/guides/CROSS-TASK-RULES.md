# 跨会话事务台规则（2026-11-05 定稿）

> 小光「穿梭多个群/对话」的正式规则。实现：`src/cross-task.js` + `src/bridge.js` + `src/mcp-snowluma-safe.js`；
> 配置：`config.json → socialV2.crossTask`；案例：`docs/cases/2026-11-05-cross-conversation-dispatcher.md`。

## 1. 它是怎么运作的

```
发起会话（群/私聊） --qq_cross_task--> 桥接校验
        │
        ├─ 通过 → 另开一个独立「事务台」DSH 会话（一次性 token + 固定读/发范围）
        │         ├ qq_peek_conversation  读指定会话的最近文本
        │         ├ qq_cross_send         发到指定目标（每条都记账）
        │         └ qq_cross_finish       结束并回报摘要
        │
        └─ 不通过 → 直接拒绝（400/403），不会创建事务台
```

- 普通会话只能**发起**，不能直接读写别的会话。
- 事务台会话**不写进 QQ 会话表**：不触发 QQ 自动回复、不参与唤醒/收尾/记忆，结束即归档。
- 事务台只能读 `readKeys`、只能发 `sendTargets`，token 一次性、不落盘、结束即作废。

## 2. 谁能发起、一天几次

| 发起人 | 次数 |
| --- | --- |
| 主人 | **不限**（任意内容） |
| 白名单里的人（`allow.private` 里的 QQ） | **不限**（按内容规则自审） |
| 好感度 ≥ 60 | **每天 5 次** |
| 其他人 | **每天 3 次** |

- 按**请求人**算，不是按会话算；
- 群聊里取**最后说话的人**当请求人；私聊取对方；
- 次数记在 `state/cross-task-daily.json`，跨天自动重算，桥接重启不清零；
- 另有全局上限：每天 200 个事务台（防刷）；同一个来源会话同时只允许 1 个。

## 3. 能读哪些、能发到哪

- 读：请求里的 `readKeys`，且必须是**当前模式 + 白名单**允许的会话；
- 发：请求里的 `sendTargets`，同样必须过白名单；
- 当前白名单：群 `200000001`、`200000002`；私聊为主人 + 已加的全部好友；
- 目标不在白名单 → 直接拒绝（不能读取/发送这个会话）。

## 4. 内容边界：允许什么

| 场景 | 规则 |
| --- | --- |
| 转给第三方（群或其他好友） | 允许，小光按内容/隐私/关系自己决定 |
| 群 → 私聊 | 允许，所有人有资格，小光自审 |
| 私聊 → 群 | 允许，小光自审（私事进群要谨慎） |
| 敏感信息 | 手机号/证件/地址/密码/令牌等命中 → 拒绝发送，并在 finish 说明 |

## 5. 事务台里小光怎么判断「该不该帮」

1. 涉及隐私/私事/别人明确说过别外传/会让人社死或起冲突 → 不转；
2. 参考关系与好感度：熟的人、正向请求优先；不熟的人让转别人私事更谨慎；
3. 只转任务要求的必要部分，不顺手扩散、不二次转述；
4. 拿不准就拒绝，并在回报里说明原因。

## 6. 转述方式

- **可以用小光自己的口吻复述**，不必逐字照搬原话（可带她的语气/吐槽）；
- 但「谁说的 / 数字 / 时间 / 条件 / 约定」不能改，不能编造、不能添油加醋；
- 必须原样保留的内容（引用、地址、ID、数字）用引号括起来，并注明来源会话；
- 发之前自检：意思有没有变？会不会让人误会成另一个人说的？
- **双轨显示**：事务台提示词里写「群名（group:群号）」/「昵称（private:QQ）」——群名给转述、号码给后端调用；对用户说话只用群名/昵称，**不要念编号**，工具参数照用 key。

## 7. 硬限制

| 项 | 上限 |
| --- | --- |
| 任务描述 | ≤ 500 字 |
| 单条发送 | ≤ 500 字 |
| 一次读 | ≤ 5 个会话 |
| 一次发 | ≤ 3 个目标 |
| 一任务发送 | ≤ 10 条 |
| 事务台时长 | 10 分钟，超时自动结束并回报 |
| 同一来源并发 | 1 个 |
| 全局每日 | 200 个 |

- 只支持**文本**；图片/语音/文件转发暂不支持。
- 读的是各会话的最近消息（`recentMessages`），图片/语音没有正文。

## 8. 事务台可用工具

| 工具 | 作用 |
| --- | --- |
| `qq_cross_task` | 普通会话发起任务（带 key/token、task、readKeys、sendTargets） |
| `qq_peek_conversation` | 事务台读某个可读会话的最近消息 |
| `qq_cross_send` | 事务台发一条文本到可发目标 |
| `qq_cross_finish` | 结束任务并回报摘要（必须最后调用） |

普通会话调用后三个会被 403；事务台 token 只能用于本次任务。

## 9. 结束与回报

- 正常结束：小光调用 `qq_cross_finish` → 桥接写审计；**默认不把【事务台】摘要发到聊天**（`reportToChat=false`），只有她在任务里用 `qq_cross_send` 发的实际内容会出现在对话里；需要看摘要时把 `reportToChat` 设为 true；
- 超时：自动结束，回报「事务台超过 10 分钟没完成，已自动结束」；
- 失败/拒绝：发起时直接返回 400/403；发送被拦截时在 finish 摘要里说明；
- 审计：每个事务台写 `state/cross-tasks.jsonl`（来源、请求人、读/发、摘要、原因）。
- **默认不显示**：事务台会话不给标题、创建后不留在 DSH 侧栏；结束后立即归档（`keepSessionMs=0`），前端看不到，也不会作为会话出现在对话里。

## 10. 配置项（`socialV2.crossTask`）

```json
{
  "enabled": true,
  "ownerOnly": false,
  "maxTasksPerDay": 200,
  "maxActivePerSource": 1,
  "ttlMs": 600000,
  "maxReads": 5,
  "maxSends": 3,
  "maxSendsPerTask": 10,
  "peekLimit": 30,
  "maxPeekChars": 4000,
  "maxTaskChars": 500,
  "keepSessionMs": 0,
  "reportToChat": false,
  "allowPrivateToGroup": true,
  "allowGroupToPrivate": true,
  "highAffectionAt": 60,
  "highAffectionDaily": 5,
  "defaultDaily": 3,
  "trustedWhitelistUnlimited": true
}
```

- `ownerOnly=true`：退回只允许主人发起；
- `allowPrivateToGroup=false` / `allowGroupToPrivate=false`：硬拦对应方向（默认交给小光自审）；
- `trustedWhitelistUnlimited=false`：白名单也按好感档位限次；
- 改完 `config.json` 需重启桥接生效；工具开关是 `socialV2.tools.crossTask`（默认开）。

## 11. 一句话版

> 主人和好友可以随时让小光跨群/跨私聊传话；其他人按好感度每天 3~5 次。读到什么、发到哪由请求指定，但都必须过白名单；该不该帮、怎么帮由小光按隐私和关系自己判断。转发可以用她自己的口吻复述，关键信息不能改；敏感内容不转；事务台 10 分钟内做完并回报。
