# 群聊按人给单独好感度 + 长久不聊淡成陌生人

日期：2026-11-05

## 1. 需求

用户原话：

> 群聊为每个你有印象的人提供单独好感度，长久不聊天印象会减少直到陌生人。

拆开：

1. 群聊里要能看到「这个人」的好感度（按人，不是按群），而不是只有一张全局名单；
2. 很久没聊的人，印象要往下掉，最终掉成「陌生人」；
3. 「陌生人」要和「没印象的人」一致：礼貌、保持距离，不装熟。

## 2. 改之前

- `affection.ps1` 只统计**分数**，不记「这个人在哪个群出现过」；prompt 里只有一张全局的「其他人好感度」列表（前 12 名）。
- 群聊时模型只能看到全局名单，不知道当前群里谁有印象、谁没有；也没有陌生人的概念。
- 衰减固定 −1/天，掉到 0 也还一直挂在名单里；新认识的人默认 40 分（朋友），比「冷淡」的人还高，语义矛盾。
- 分档最低只到「冷淡」（<21），没有「陌生人」。

## 3. 改动

### 3.1 `state/tools/affection.ps1`

- **群关系**：解析日志时同时记录 `people[qq].groups`（TA 在白名单群出现过）；当天日志 + 回看最近 6 天日志补历史；每天运行会沿用已有群关系（今天没说话也不会忘）。
- **分档**：新增 `陌生人`（<10）；`冷淡` 改为 10–20；其余不变（眼熟 21–40 / 朋友 41–60 / 亲近 61–80 / 最喜欢 81+）。
- **初始分**：新认识的人从 **10（冷淡）** 开始（原来 40=朋友）。
- **加速衰减**：不互动时 1–13 天每天 −1；14–29 天 −2；30 天以上 −3，直到 0（陌生人）。
- **日常层**：只列 ≥10 分的人；末尾加「另有 N 人已淡成陌生人」；规则改成「名单里没有的人＝陌生人，礼貌保持距离」+「好感度会随时间淡，掉到陌生人就当刚认识的对待」。

### 3.2 桥接（`src/`）

- 新模块 `src/affection-impressions.js`（纯函数，单测覆盖）：
  - `friendsInGroup(affection, 群号)`：只取 `groups` 含该群、分数 ≥10 的人，降序、最多 12 个；
  - `formatGroupImpressionsLine()`：生成 `【本群印象】名字 分数/100（band）｜…；没列到的人＝陌生人（礼貌、保持距离，不主动熟络）。`
  - `affectionBand()`：与脚本 `Band()` 同源。
- `src/voice-affection.js` 的 `loadAffection()` 保留 `groups`/`lastSeen`（旧文件没有就空数组，不串群）。
- `src/bridge.js`：
  - `affectionGroupLine(key)`：群聊才生成，私聊空串；
  - 唤醒提示词在「会话身份」之后注入这一行（每轮都在，换群自动换人）；
  - `GET /api/socialV2/prompt` 增加 `groupImpressions` 字段（qq_get_prompt 也能看到）。
- 语音门槛的「名单外分数」同步改为 10（陌生人），和分档一致。


真机（2026-11-05）：

- 手动跑新版 `affection.ps1` 后，`affection.json` 里出现群关系：
  `200000001` 群成员：sensei 100、群友D 59、群友A 51、讨厌一切吐烟… 50；
- 桥接重启后 `GET /api/socialV2/prompt?key=group:200000001` 返回：
  `【本群印象】sensei 100/100（最喜欢）｜群友D 59/100（朋友）｜群友A 51/100（朋友）｜讨厌一切吐烟吐我脸上的抽烟傻逼 50/100（朋友）；没列到的人＝陌生人…`
- 私聊 `groupImpressions` 为空串（不串群）；
- 陌生人语音 dryRun：`好感度 10 低于 60：语音要少用，等他先开口再回`。

## 5. 边界 / 风险

- 群关系来自 SnowLuma 日志里**白名单群**的发言记录（最近 7 天 + 历史累计）。只在群里潜水、从没发过言的人不会被记入；
- 好感度脚本每天 23:50 才跑一次：当天新认识的人要到下一次运行才进名单（这是原来的节奏）；
- 换角色包后 `groups` 从新角色自己的 `affection.json` 读，不共享；
- 「陌生人」不是被删除：还留在文件里（分数 0–9），只是不再出现在「本群印象」和「其他人好感度」里；
- 语音门槛同步用 10 分（陌生人），低于 60 本来就走低频档，实际行为不变。
