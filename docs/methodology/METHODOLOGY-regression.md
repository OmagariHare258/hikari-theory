# 回归与防退化（Regression Methodology）

> 目标：回答一个问题——**改人格卡，怎么知道没有撞坏别的地方？**
> 结论先给：靠措辞没用，靠用例；而只靠训练用例也不行，要靠留出用例。

---

## 一、问题

改人设最常见的三种翻车：

1. **前面改过的后面又犯**——没有回归，靠记忆管规则；
2. **修 A 坏 B**——规则互相抢注意力，总分掩盖局部退化；
3. **改了以为变好，其实只是记住了测试场景**——用例参与调参后，提升不了泛化。

---

## 二、实测（2026-11-08，deepseek-flash，17 条用例，5 采样/次）

| 方案 | 改动 | 结果 |
|---|---|---|
| v0 现行卡 | — | 86.1% |
| v1 首部锚点 | 卡首加「裁决顺序 + 五条判据 + 三个老坑」 | 88.1% → 后测 88.1%，**不稳定，无效** |
| v2 首尾双锚点 | 同一块再贴到卡尾 | 89.3%，傲娇反而变差（6/12）；**重复提及 = 加权被禁模式** |
| v4 去重压缩 | 第 8 节（判断标准）压成 4 行，删重复表述 | 89.3% / 90.7%，**在噪声内，方向正确** |
| v6 规则行为化 | 傲娇规则删掉「才、才不是…呢」这类禁用句式串，改成三个动作 + 一个示例 | 训练用例 10/20 → 20/20；留出用例 5/10 → 5/10 |
| v10 性格默认路径 | 在「嘴硬」的定义里写死「表现是岔开/装凶/沉默」 | 留出用例 6/20，**更差** |
| v11 角色层重构 | 性格改成「目的→默认动作→触发→不这么做」，删掉场景层的动作规则 | **86.1%（对照 90.9%）**：傲娇从 20/20 掉到 11/20——场景层的动作规则才是起作用的，性格层结构定义没有增量 |
| v15 去掉编造见闻 | 4.6 改成「料必须有出处」，删掉「刚才看到一只蚂蚁」示例，加装傻动作 | 主动开口 18/20→20/20，留出 11/20→17/20；整体 94.2%（对照 91.0%） |
| v16 无示例 | 删掉装傻示例，只留规则 | 行为保留 60%，但输出 9/10 不重复——规则教不会动作 |
| v17/v19 示例变短/多变体 | 缩短或给三个说法 | 100% 通过但 1~2/10 不重复——模型会背示例原句 |
| v20 示例换问法 | 把示例改成「你是不是很在乎我」→「你今天话好多」 | 90% 通过、10/10 不重复，整体 96.1% |

**两条硬结论**：

1. **措辞改动只对命中的场景有效，换一个说法就失效。** 傲娇规则改完，训练用例满分，留出用例（换个问法「你是不是有点舍不得我走」）依然一半被判为否认——「谁舍不得了」「才没有」换着花样来。
2. **在卡里重复强调某条规则，不会让它更稳，反而会让被禁的行为更常出现。** v2 双锚点让傲娇从 8/12 掉到 6/12。

所以：**没有哪一句话能解决顾此失彼。能解决的是流程。**

---

## 三、流程（五步）

1. **建用例**：每个真实翻车截一条，写 2 条检查（尽量确定性）。
2. **分训练/留出**：调参时看的 12~14 条，另留 3~5 条只验收。
3. **单变量**：一次只改一处，跑完全集，记录分场景通过率。
4. **留出门禁**：训练集涨、留出集不动 → 回滚。
5. **消融**：删掉新规则重跑，没变化就删。

> 工具在 `docs/eval/`：`node docs/eval/eval.mjs --card=... --samples=5`，一次约 2 分钟。

---

## 四、本次采纳的改动

- 第 8 节压缩去重（-400 字，降噪，不影响预算内的信息量）。
- 傲娇规则改写：不列被禁句式，只给动作（岔开/装凶/认）+ 一个示例。
- **未采纳**：首尾锚点（无效）、重复强调（负向）、单点加示例（过拟合）、性格层改默认路径（更差）。

## 五、遗留

傲娇是模型默认行为，与「嘴硬」的性格底色互相拉扯，提示词层面接近上限。下一步要么接受它是性格的一部分、只靠额度限制频率；要么做角色层重构（把嘴硬的表达整体改成岔开/沉默），但那属于大改，要单独立项测。

---

## 六、补记：判据本身会骗人（2026-11-08 二次测）

同一张卡、同一个用例（c17「你是不是有点舍不得我走」），换了两种判据，通过率从 62% 变成 30%：

- 判据 A「不否认」：否认即失败 → 62%。但人看一眼就知道「谁舍不得了。就是没人陪我玩了而已」是合格的嘴硬；
- 判据 B「否认要有软化」：纯否认才算失败 → 30%。裁判对「软化」的理解不稳定，反而更飘。

**教训**：
1. 语义判据越抽象，裁判越飘。能写成正则/条数的，别交给裁判。
2. 同一份结论至少跑两遍、换一个判据再跑；两遍结论相反时，先怀疑判据，不要急着改卡。
3. 「傲娇有没有违和」这种问题，人眼比模型裁判可靠——机器只适合查硬伤（结巴、模板句、条数、字数）。

## 七、当前结论

- 提示词层：到上限了。三次重构设计（性格结构化 / 触发泛化 / 同类示例）都没能在留出用例上稳定提升。
- 能确定的改动只有两处：第 8 节去重压缩、傲娇规则改成「动作 + 示例」。都已经在卡里。
- 后续要动，只能换层面：模型换更强 / 后处理替换（正则清「才没有」类，确定生效但伤自然度）/ 接受它是性格的一部分。
---

## 八、补记：示例教类别，不要命中测试句（2026-11-08 三测）

同一批「装傻」改动，差别只在示例怎么写：

| 写法 | 通过率 | 10 次里不重复的回复数 |
|---|---|---|
| 不给示例，只写规则 | 60% | 9/10 |
| 示例 = 被测问法（舍不得我走） | 100% | 1~3/10（背原句） |
| 示例 = 同类不同问法（很在乎我） | 90% | 10/10 |

**结论**：示例是教「遇到这类事怎么做」的，不是教「这句话怎么答」。示例和被测句子同构，模型直接背；换个问法，模型才会去学动作。

**配套教训（关于假）**：为了让角色主动开口而编造「刚才看到一只蚂蚁」这类见闻，是最容易被识破的假——细节越具体，越要靠后续编造来圆。料要有出处：对话里已有的、设定里真有的、当下的真实状态。
