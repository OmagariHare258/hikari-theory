# B站 养号期（评论 state=17 之后）

> 场景：新设备登录 / 改密码 / 清登录态后，B站 把评论打成 `state=17`（仅自己可见），主人看不到、收不到 @。
> 这里记录养号期的临时措施和恢复标准。

## 临时措施

| 项 | 平时 | 养号期 |
|---|---|---|
| 普通评论 | 15 条/天 | **5 条/天** |
| 搭话（`--ta`） | 5 条/天 | **2 条/天** |
| 回找我的人 | 30 条/天 | **10 条/天** |
| 分享通道 | 评论区 @ 主人 | **B站 私信**（`share.via="dm"`） |

配置位置：`~/.dsh/surfcore/bili.config.json` 的 `limits` 与 `share`。

## 自动巡检

每天 10:00 跑一次 `scripts/bili-state-watch.ps1`，检查一条「哨兵评论」是否已公开：

- 隐藏中：往 `state-watch.log` 记 `still hidden`；
- 已公开：写 `state-ok.json`，并（带 `-Notify` 时）发一条 B站 私信提醒主人。

Windows 计划任务名：`Hikari-Bili-StateWatch`（需要真实 rpid / oid 参数，见脚本用法）。

## 恢复标准

满足以下条件再把 `share.via` 切回 `comment`、额度调回平时：

1. `state-ok.json` 出现（哨兵评论公开）；
2. 连续 3 天新评论都能被非登录态看到；
3. 没有新的验证码/风控提示。

## 如果两周后还是 17

说明不是"养"能解决的：账号被标记（营销号/机器行为）或设备风险太高。建议换号，或走 B站 人工申诉。

## 其它加速项

- 完成实名认证；
- 等级升到 3+（看视频/点赞/投币，别刷）；
- 昵称头像别再改，设备/IP 稳定；
- 少发链接、少 @、同一视频别重复评论。
