# 生活模拟（睡眠/吃饭/疲惫）

目标：让小光像一个有作息波动的小孩，而不是随叫随到的接口。**但这些状态只在后台影响语气和速度，不主动播报。**

## 每天生成一套作息

`src/life-sim.js` 按「日期 + 角色 id」确定性生成，同一天稳定、不同天波动：

- 四种底子：早睡早起 / 正常 / 晚睡晚起 / 乱七八糟；
- 入睡时间在 22:00–01:30 之间浮动，睡眠 5.8–8.4 小时；
- 午睡概率约 55%，12:50–14:00 之间，15–60 分钟；
- 早/午/晚饭时间各自带 30–55 分钟随机。

不写状态文件，纯时间推导；桥接重启不会重置当天的作息。

## 影响什么

| 状态 | 对话语气 | 回复延迟 | 主动行为 |
|---|---|---|---|
| 正在睡 | 刚被吵醒、困、有点烦；短、慢、不热情 | 25–60 秒 | 暂停主动私聊/群搭话 |
| 午睡 | 懵、不情愿 | 15–40 秒 | 暂停 |
| 刚醒 | 没缓过来，短、慢 | 8–20 秒 | 正常 |
| 吃饭 | 手上不利索，短 | 4–11 秒 | 暂停主动 |
| 深夜 | 困、耐心少 | 3–9 秒 | 暂停主动 |
| 精力 ≤25 | 累、不想多动 | 3–9 秒 | 正常 |

精力由睡眠时长、清醒时长、午睡、吃饭和深夜惩罚共同计算，带每日随机偏移。

## 不表演

- 每轮只注入一句【身体状态】，明确写「只影响语气和速度，不要主动说在睡觉/吃饭/被吵醒，不要解释为什么回得慢」；
- 人格卡 4.5 加「作息不播报」；
- 被问就短答「困」「不想动」，不报时间表、不演段子；
- 没有「小光去睡觉了」这种系统通知。

## 配置

目前是代码内参数（`src/life-sim.js`），没有暴露到设置页。想调节奏直接改：
- `sleepStart` / `sleepHours` / `napChance`；
- `delayFor` 的延迟区间；
- `promptFor` 的状态文案。
