# 跨会话共享记忆

问题：小光在 A 群/私聊知道的事，换到 B 群/私聊就不知道——「同一个小光」只在人格和好感上成立，事实层没有互通。

## 机制（两层）

1. **显式条目**：`state/shared-memory.json`，最多 200 条，每条 ≤300 字，带 tags/sourceKey/时间。
2. **自动汇总**：唤醒时扫描所有会话最近 7 天别人说的、命中「事实/约定」关键词的句子，取最新 5 条；加上显式条目最多 8 条，注入。

关键词：夺冠/冠军/赢了/输了/比分/结果是/结果/定了/约定/说好/记住/记一下/通知/改到/时间是/地点/决赛/总冠军。
过滤：4–120 字、敏感信息命中不记、同一句不重复。

> 不再自动捕获她自己的发言——试过，会把「小光也把跨会话记忆接上了」这种废话记进去。重要的由她自己用 `qq_shared_append` 补一句。

## 注入

注入块不叫「跨会话记忆」，叫「小光记着的事」——像学生自己记的小本子，不是系统通知：

```
【小光记着的事】[11-17] …｜[11-18] …
【小光记着的事】这些是小光自己记的，不是系统通知；用的时候像自己想起来的，别在别的会话点出是哪个群、谁说的；记不清就说记不清。
```

## 工具

- `qq_shared_append(text, tags?)`：手动写一条；
- `qq_shared_get()`：读最近 50 条。

## 翻别的会话

主人私聊里，小光现在可以：

- `qq_list_conversations`：列出所有会话（key、消息数、最后一条摘要）；
- `qq_read_conversation(targetKey, limit)`：读任意会话最近 N 条（≤50）。

另外唤醒时会给主人私聊注入【别的会话最近】：除当前会话外，最近 24 小时每个会话各 2 条摘要（最多 6 个）。

权限：只有主人私聊能读别的会话；群聊里只能读自己。只读，不能写、不能替别人发。

## 边界

- 只记**事实/结果/约定**，不记闲聊；不确定的不记；
- 敏感信息（token/手机号/身份证等）由 `SENSITIVE_RE` 过滤；
- 条目会过期吗：目前不自动删，最多 200 条，后续可以加 30 天淘汰；
- 注入预算：8 条 × 120 字，最多约 1000 字，不影响人格卡注入。
