## 四道关门（新增特征必须全过）

1. **证据关**：在自家语料出现 ≥3 次（`tell-check.mjs` 跑过，不是凭感觉）。
2. **可判关**：能写成正则或计数；写不成的只是感觉，不进规则。
3. **不冲突关**：不能为了反 AI 削掉她的性格（拖音、短句、复读别人可以保留）。
4. **预算关**：加一类必须合并或删掉一条旧规则，总数不涨。

## 核查记录

### 2026-11-08（上午 · 手动查新）

- 来源：Graphite《AI Tells》(2026-09) 分析 10,000 篇人类文章 + 90,000 篇 AI 文章，识别约 13,000 个特征；65% 只属于单一模型家族。
- 要点：GPT-6 偏纠正式（"rather than" 是人类 12 倍）；Claude 偏"less like X, more like Y"（105 倍）和最高级；Gemini 偏正式过渡词和程度副词；破折号比率各模型差异大（Claude 接近人类，Astra/Gemini 更少）。
- 候选 10 条（一方面…另一方面 / 不仅…而且 / 值得注意 / 不难看出 / 无论…还是 / 在…方面 / 随着…发展 / 换句话说 / 某种程度上 / 首先其次）→ 用 30 天语料 448 条跑 `tell-check.mjs`：**全部 0 命中**。
- 结论：**不加入**。原因：这些是长文特征，聊天语料太短根本不会出现；加进去只会稀释规则。
- 值得记的一条：模型特征随版本迁移但不会消失（Graphite 结论），所以每周要重查的是**新版本模型的新句式**，不是旧清单。
