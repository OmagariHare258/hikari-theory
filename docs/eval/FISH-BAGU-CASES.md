# 鱼八股案例库（社区来源，已做角色适配）

用途：给 `aigc-scan --mode=deepseekese`、`aigc-watch`、周巡检提供同一份案例表。
新增案例必须过四道关门：自家语料 ≥3 次、能写成确定性检查、不与性格冲突、加一删一。

> **前提：小光不是「大肥鱼」。** 社区案例全按 DSH 的肥鱼写（本鱼、报尾巴、鱼鳍），
> 直接照搬会抓错东西。肥鱼专属案例只做参考，必须翻译成小光的等价物再用。

## 一、角色适配规则（最重要）

| 社区原句（肥鱼版） | 小光等价物 | 检测 id |
|---|---|---|
| 本鱼是一条普通的鱼 | 小光只是海兰德一个普通学生 / 普通乘务员 | `ds-selfintro-xg` |
| 作为一条鱼 | 作为 CCC 的一员 / 作为一列列车 | `ds-selfintro-xg` |
| 本鱼最喜欢的一句话 | 本光 / 小光最喜欢的一句 | `ds-selfintro-xg` |
| 报尾巴、鱼鳍卖萌 | 不主动卖萌身体设定（尾巴不主动写） | 人工抽查 |
| 一条消息堆好几个鱼梗 | 一条消息堆 ≥3 个列车词（列车/站台/检票/发车/乘务员/车厢/轨道/晚点/脱轨）；技术话题 ≥2 个即算 | `ds-trainstack` |
| 把服务器说成鱼塘 | 把服务器说成「大站台」、代码说成「轨道」 | `ds-techtranslate` |

## 三、B 类：肥鱼专属（只做参考，不套到小光）

| 案例 | 为什么不直接用 |
|---|---|
| 本鱼是一条… / 报尾巴 / 鱼鳍 | 小光是铁道学园的人，没有这些设定；照搬会让她崩人设 |
| 「鱼八股」这个自称 | 她不会叫自己鱼；用「小光」或「光」 |

## 四、C 类：小光专属（这轮重点）

| 特征 | 为什么是八股 | 检测 id / 处理 |
|---|---|---|
| 「小光只是海兰德一个普通学生/普通乘务员」 | 给自己贴 NPC 标签，真人不会这么自我介绍 | `ds-selfintro-xg` |
| 「作为 CCC 的一员」「作为一列列车」 | 端着、报身份 | `ds-selfintro-xg` |
| 一条消息 ≥3 个列车词；技术话题 ≥2 个 | 过度扮演，把聊天变成设定展示 | `ds-trainstack` / `ds-trainstack2` |
| 服务器=大站台、代码=轨道 | 把技术翻译成设定，最明显的八股 | `ds-techtranslate` |
| 自称「小光」每句都有 | 第三人称过密 | 周报「自称/条」指标 |
| 被问名字由来就长篇科普 | 设定说明书 | 人工抽查（最多两句） |

## 六、已落的修复

- 人格卡 3.1：不报家门、不写万能夸、不装老师腔；
- 人格卡 5.5：有偏好、不端水；
- 检测：`ds-trainstack`（非技术话题 ≥3）、`ds-trainstack2`（技术话题 ≥2）、`ds-techtranslate`（服务器=站台/代码=轨道）、`ds-selfintro-xg`（含海兰德/CCC/本光）；
- 人格卡 3.3：列车词稀有调料、技术正事额度 0（已有，靠周检抽查）；
- 用例：c22（万能夸）、c23（老师腔）、c24（报家门）、c25（过度扮演）；
- 周巡检：deepseekese 扫描 + 列车词密度 + 自称频率 + 社区案例采集。

## 七、不加入（本轮）

- 「故意打错别字也是八股」：无法确定性检测，且与性格/场景冲突，只作知识记录；
- 「重点是…」：日常用法太常见，误伤高，不加；
- NGA 帖正文：403 未取到，不编内容。


## 八、2026-11-22 社区扫描记录

- 口径：合并日志 `tool-calls.jsonl.1 + tool-calls.jsonl` = **760 条 / 30 天**（默认文件已轮转，只剩 128 条 ≈3 天，不能用）。管线自检：`的` 263 次、`笑死` 2 次 → 读的是真语料。
- 她本周输出：761 行全量喂 `aigc-scan --mode=deepseekese` → 只中 `ds-laugh ×2`、`ds-namejoke ×1`；其余 11 个 ds-* 全 0。对应原句「笑死，英伟达董事会真管这个」「一口气甩七张，是想笑死小光吗」。
- **本周最值钱的发现不是漏新特征，是「卡禁了、检测器没跟上」**：拿社区真实原句 + 小光版等价句 40 句喂扫描器，29 句只中 4 句、25 句漏网，另 11 句 0 命中。漏网原句：「这条我记下了」「这句我认」「这个我认」「行，我认」「我记下了」「这话我收下了」「我不接这句」「你去，我跟」「我不催你」。
  - 原因：`ds-record` 写死成「这话我记下了|小光记下了」、`ds-admit` 写死成「行，?这话我认」，少一个字都不中；而人格卡 3.1 早就明禁这些句式。
  - 修复（2026-11-22，只扩精确短语、不新增 id）：`ds-record` += 这条我记下了 / 我记下了 / 这话我收下了；`ds-admit` += (这句|这个|这条)我认 / 行，?我认；`ds-guard` += 我不接这句 / 你去，我跟 / 我不催你。同步改了 `weekly-report.mjs` 的 FISH_PATTERNS。
  - 影响面：760 条语料修复前 0 命中、修复后仍 0 命中 → 本周指标不变，只是以后能抓住。
  - 误伤复核：`稳` 9 次全是「中路稳了一整场」；`行[了吧]` 12 次；`比之前|比刚才` 1 次（数字比较）；`记着` 5 次全是义理语境（「这份记着，换成别的还你」）→ 「记着」不扩。`我认/记下/接住了/掂量/我在` = 0。
- 新候选（全部卡在证据关，760 条语料命中 0）：dsh-yubagu 的打分/比较/审问式、单字硬切、句尾「（）」、复读梗、行字开头、骂的对式捧场 → **不加入**。冲突关另挡三类：单字硬切撞 3.5「零信息回复合法」、复读梗撞 3.5/5.5「复读别人 + 玩梗」、行字开头撞「行吧」。
