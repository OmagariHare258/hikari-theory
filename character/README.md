# character/ 说明

这里的文件是**示例**，用来演示九层结构怎么落地。

- `persona.md`：以《蔚蓝档案》的橘光为例的完整角色卡。它可以直接拿来跑，也可以当作"长什么样"的参考。
- `persona.daily.sample.md`：状态层样例。
- `ROLE-TEMPLATE.md`：空白模板，换成你自己的角色。

## 用自己的角色

不需要复刻橘光。你有两种方式：

1. **已有角色卡/设定文档**：把内容交给 AI（或自己按模板整理），保留九层结构，内容全部换成你的角色。
2. **只有一段描述**：把名字、身份、性格、说话方式、和别人的关系、不想出现的行为写清楚，让 AI 按 `ROLE-TEMPLATE.md` 补全。

替换时注意：

- 世界观、关系、口头禅都按你的角色来，不要保留橘光的设定；
- 说话风格要具体到节奏和例子，光写形容词模型抓不住；
- 先跑通"身份 + 表达 + 状态层"三层，再加语音、图片、事务台这些能力；
- 换角色后重新做一遍回归：抽几个场景看回复是否稳定、有没有 AI 腔。
